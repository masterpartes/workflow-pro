AVK Parts Bookmarklets

Drag each green button to your bookmarks bar. Use them on avkparts.lt while logged in.

📋 Step 1 — AVK: Fill Search

Click this on avkparts.lt with the Bulk parts search modal open. It reads your clipboard (one OE number per line) and submits the search automatically.

AVK: Fill Search
  1. Copy OE part numbers to clipboard (one per line)
  2. Go to avkparts.lt and open the Bulk parts search modal
  3. Click AVK: Fill Search — it fills and submits automatically

📊 Step 2 — AVK: Get Prices v3 — auto-copy

After the results load, click this. It extracts all prices, shows a summary overlay, and copies the results as JSON to your clipboard automatically — no need to click a copy button, just switch to Excel and click AVKI.

v2 fix: the original version scraped for <table>/<tr> elements, but avkparts.lt's bulk results aren't a table at all (it's div-based), so it silently found zero rows every time. Rewritten against the real structure: .bulk_single_item (one per searched part, with the searched code in .single_bulk_code) containing several .item rows (one per supplier), each with .column_provider (supplier code, e.g. "PSA E"), .column_price_no_tax and .column_price_with_tax. Verified against a real 13-part bulk search (115 supplier rows extracted correctly). Also fixed the price parser, which was mangling decimals (misreading "€81.85" as 8185).

v3 fix: copying used to require clicking "Copy JSON" in the overlay — if you skipped that (or the click didn't register), Importar AVK in Excel would fail with a generic error, since it just found whatever was already on the clipboard from before. Now the JSON copies the instant the overlay appears; the button is only there in case you need to copy it again.

AVK: Get Prices
  1. Wait for the AVK results to fully load
  2. Click AVK: Get Prices
  3. An overlay shows all suppliers and prices — click Copy JSON
  4. The JSON is now in your clipboard (paste into Claude or wherever needed)

JSON format: [{"part":"A0004208503","supplier":"VALEO","price_eur":29.15}, ...]

Workflow summary:
Copy OE numbers → open avkparts.lt bulk modal → click Fill Search → wait for results → click Get Prices → JSON in clipboard.
